## 📖 Sobre o Projeto

O **Computador de Voo** é uma ferramenta mobile desenvolvida para democratizar e modernizar o acesso a tecnologias de planejamento de voo. O objetivo principal foi digitalizar a tradicional "Régua de Voo" (Computador de Voo analógico/E6B), tornando os cálculos de navegação aérea mais acessíveis, intuitivos e eficientes para pilotos de diversos níveis.

Este projeto foi realizado no âmbito do **Projeto SUPER**, uma parceria de Pesquisa e Desenvolvimento (P&D) entre a **Universidade Federal do Amazonas (UFAM)** e a **Samsung Eletrônica da Amazônia**.

### 🎯 Objetivo
Transformar instrumentos físicos de medição aérea em uma interface digital responsiva, garantindo precisão matemática e usabilidade (UX) aprimorada.

## ✨ Funcionalidades Principais

*   ✅ **Digitalização da Régua de Voo:** Interface interativa que simula e automatiza os cálculos da régua física.
*   ✅ **Cálculos de Navegação:** Planejamento de rota, consumo de combustível, velocidade e tempo.
*   ✅ **Interface Acessível:** Design implementado com foco em usabilidade, facilitando a leitura de dados complexos em telas móveis.
*   ✅ **Otimização de Operações:** Ferramenta leve projetada para reduzir o tempo de planejamento de voo em solo.

---

## 🧠 Desafios e Desenvolvimento (P&D)

Este projeto foi desenvolvido ao longo de **12 meses (480 horas)**, com foco em rigor técnico e qualidade de software.

### 🤝 Trabalho Multidisciplinar
O desenvolvimento não foi isolado. Atuei como **Desenvolvedor Mobile Principal**, integrando demandas de diferentes áreas:
1.  **Engenharia de Requisitos:** Colaboração com *Pesquisador da área* para entender a lógica física da régua de voo e traduzi-la para algoritmos em Dart.
2.  **UI/UX Implementation:** Trabalho conjunto com *Designer* para implementar fielmente as telas e a experiência de usuário planejada.
3.  **Programação em Par:** Suporte de auxiliar técnico para revisão de lógica e otimização de código.

### 💡 Destaques Técnicos
*   Tradução de lógica matemática complexa (física) para lógica de programação.
*   Gerenciamento de estado para atualizações em tempo real dos cálculos.
*   Documentação técnica contínua para reportes ao Projeto SUPER.
